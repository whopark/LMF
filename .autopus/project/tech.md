## Architecture Patterns

| 패턴 | 적용 위치 |
|---|---|
| MVC-lite | backend: routes/ (controllers) + models/ |
| SPA + REST | frontend는 단일 React 트리, backend는 무상태 REST |
| Static-after-build | backend가 `frontend/dist`를 정적 서빙 + catch-all로 SPA 라우팅 |
| Allowlist update | `routes/api.js`의 `ALLOWED_UPDATE_FIELDS` (mass-assignment 방어) |
| Regex escape | 사용자 검색어를 정규식으로 변환 시 escape (`api.js:54`) |
| Schema validation | `findByIdAndUpdate({ runValidators: true })` |
| Rate limiting | `routes/llm.js`만 분당 N회 제한 (LLM 비용 보호) |
| Body size limit | `express.json({ limit: '32kb' })` |

## Security Posture

- API key는 `.env`에서만 (gitignored)
- ANTHROPIC_API_KEY 누출 시 LLM 라우트로만 영향 (rate limit + 32KB body limit이 한도 캡)
- CORS: whitelist 방식 (SEC-001) — `CORS_ORIGINS` 환경변수로 허용 origin 설정
- API Key 인증: timing-safe 비교 (SEC-002) — PATCH 엔드포인트 보호 완료 (SPEC-AUTH-001)
- 보안 이벤트 로깅: JSON 구조화 로그 (SEC-003) — AUTH_FAILURE, AUTHZ_DENIED 이벤트 기록
- MongoDB injection: regex escape 적용, query는 정적 필드만 사용
