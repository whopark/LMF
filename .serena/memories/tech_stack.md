# Technology Stack

## GUI Application (gui/)

### Backend (gui/backend/)
- **Runtime**: Node.js
- **Framework**: Express.js 4.21
- **Database**: MongoDB via Mongoose 8.3
- **CORS**: cors 2.8

### Frontend (gui/frontend/)
- **Framework**: React 19.0
- **Build Tool**: Vite 6.2
- **UI**: lucide-react (icons), framer-motion (animations)
- **HTTP Client**: axios

## Autopus-ADK (autopus-adk/)
- **Language**: Go 1.26
- **CLI Framework**: Cobra
- **UI**: Bubbletea, Lipgloss, Huh
- **Testing**: testify
- **Config**: YAML v3
- **Utilities**: xxhash, uuid, websocket

## Medical Imaging (User Interest)
- DICOM image processing
- Chest X-ray analysis
- Rib fracture detection (L1-L10, R1-R10)
