## /auto sync 시 영향

`/auto sync {SPEC-ID}` 호출 시:
- **Phase A (module commit)**: 본 workspace는 단일 repo 구조이므로 module과 root 구분 없음 → 단순 단일 commit
- **Phase B (meta commit)**: 별도로 분리하지 않음 (root가 곧 module)

`autopus-adk/`는 외부 repo이므로 sync 대상 아님.
