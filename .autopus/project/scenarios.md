- **Depends**: N/A
- **Status**: active

### S2: items_pagination — 페이지네이션 동작

- **Command**: `curl -s "http://localhost:5000/api/items?year=2024&page=1&limit=10"`
- **Precondition**: 공통 + 2024 데이터 존재
- **Expect**: 10개 이하 items + total/totalPages 메타
- **Verify**: status_code(200), json_path("$.items.length", "<=10"), json_path("$.total", number)
- **Depends**: S1
- **Status**: active

### S3: items_search_regex_safe — 검색 입력 정규식 escape

- **Verify**: status_code(200), json_path("$.total", "<{전체 카운트}")
- **Depends**: S1
- **Status**: active

### S9: llm_reason_generation — 수정사유 LLM 생성

- **Command**: `curl -s -X POST -H "Content-Type: application/json" -d '{"previous":{"question":"old"},"current":{"question":"new"},"changeType":"MODIFIED","summary":"질문 변경"}' "http://localhost:5000/api/llm/reason"`
- **Precondition**: 공통 + ANTHROPIC_API_KEY 유효
- **Expect**: 200 + `{ reason: "한국어 1~2문장" }`
- **Verify**: status_code(200), json_path("$.reason", string), response_time_ms(<10000)
- **Depends**: N/A
- **Status**: active

### S10: llm_rate_limit — 분당 한도 초과 차단

- **Command**: `for i in $(seq 1 25); do curl -s -o /dev/null -w "%{http_code}\n" -X POST -d '{"current":{"question":"test"},"changeType":"NEW"}' -H "Content-Type: application/json" http://localhost:5000/api/llm/reason; done`
- **Precondition**: `LLM_RATE_LIMIT_PER_MIN=20` (기본)

- **Status**: active
