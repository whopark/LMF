# Code Style and Conventions

## JavaScript/Node.js (gui/backend/)
- CommonJS modules (require/module.exports)
- Express route handlers
- Mongoose models for MongoDB

## React/JSX (gui/frontend/)
- ES6 modules (import/export)
- Functional components with hooks
- Vite for bundling
- CSS files for styling

## Go (autopus-adk/)
- Go 1.26 standard formatting (gofmt)
- Cobra for CLI commands
- testify for testing
- 300-line file limit (Autopus convention)
- Single responsibility per file
- @AX tags for AI-readable documentation

## General Conventions
- Meaningful variable/function names
- Comments for complex logic
- Error handling with context
- Tests alongside implementation

## Medical Imaging Code
- DICOM metadata handling
- Arrow indicators on images
- Systematic rib analysis (L1→L10, R1→R10)
